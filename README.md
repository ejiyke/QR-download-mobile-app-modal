# ConnectNigeria Quote Request & Download Mobile App Modal

A modern, responsive landing page and interactive mobile bottom-sheet modal for **ConnectNigeria Quote Request**, built directly from Figma designs (`node-id=2626-1539` and `node-id=2610-1444`).

## ✨ Features

- **Mobile Download App Modal (Figma 2610:1444)**:
  - Mobile bottom-sheet with drag handle, bold typography, and 3D angled smartphone mockup.
  - Official store buttons: **Google Play Store** (brand green) and **Apple App Store** (dark navy).
  - Automatically pops up **30 seconds** after page landing and opens on demand from any store button.
- **Hero Section**:
  - 3 floating tilt polaroid professional cards (Painter, Laundry, Cleaner).
  - Search bar with instant service quote request and 10 quick category chips.
- **Popular Categories Grid**:
  - 12 photographic category cards with smooth zoom hover states and "See All" expander.
- **For Customers & Phone Mockup**:
  - 4-step workflow cards and interactive iPhone frame displaying live app UI.
- **For Vendors & Live Earnings Showcase**:
  - 4 vendor value cards and floating weekly earnings trend badge (`₦180,000.00`).
- **Vendor Pricing Plans**:
  - Starter (₦5,000), Standard (₦10,000), Pro (₦20,000 - Most Popular), and Business Elite (₦100,000/yr) with 50% discount tags.
- **Video Walkthroughs & FAQ Accordion**:
  - Video guides for Customers and Vendors.
  - Interactive accordion tabs with smooth expandable drawers.
- **Multi-step Quote Request Wizard**:
  - Interactive 3-step project wizard with live reference ID generation.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve locally:

```bash
# Python
python -m http.server 8080

# Node.js
npx serve
```

## 🛠️ Tech Stack
- HTML5 / Vanilla CSS3 / Modern JavaScript (ES6+)
- Google Fonts (`Plus Jakarta Sans`, `Inter`)
